## 狀態讀取與回復

GET /api/performance/stats 的 legacy_evidence_revisions，分開提供 approved_scope_count、terminal_scope_count、awaiting_maturity_count、mature_unscored_scope_count 和 revisions。分母按 scope 去重，不把每天追加版本當新增股票樣本；交易日未知時 maturity counts 為空、顯示未確認。

可用專案 Python 執行 scripts/manage_legacy_evidence_revisions.py --summary；或以 mode=ro 讀 operational.sqlite3 的 trade_evidence_revision_batches_v1／trade_evidence_revisions_v1。停用回復指令為 --deactivate-batch hcs-legacy76-df03143a097e1e25，只改 active=0，保留新版本與全部原件。
