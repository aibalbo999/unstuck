# 台股兩週研究：偏誤與評估邊界

績效 API 的 population 從完整台股 v4 report index 所有版本建立 5、10 日預期評估槽。以最近完成交易日判定成熟；未知日曆不推測。分列未成熟、到期未保存、缺行情、無計畫、觀望、未成交及原結果狀態。索引不含已移除檔案時，不能稱歷史全市場母體；保存結果不在索引中另列 orphan。

主要比較固定 10 交易日；同股票同日按索引報告時間選最早版本，再按時間選不重疊窗口。選擇不讀 outcome，不能用後來有結果的版本替換未評分的早版。不同股票仍可能相關，候選決策數不是獨立統計樣本數。原始结果保留；歷史未帶新日曆、價格及成本契約者只供描述，不自動升級。所有已保存結果不會被例行任務重新覆寫；2026-10-02 以前的缺保存結果也不自動填寫，須明示 allow_historical_evaluation 才能評估；大量重算需要另外指定範圍與可復原方案。

新正式交易評估比對官方日曆 N 個完整交易日，不以補到後來第 N 根行情延長窗口。價格查找不向未來補值；月度新買入以報告後首個已觀察日作保守價格起點，不假設盤後訊號可在當日收盤成交。

台股普通股計畫須確認未調整行情價格口徑、合法格點及公司行動欄位完整；有分割或股息事件、調整口徑、類型未知、上櫃格點未核對時未評分，不自動調價。報告原價位及來源保留。來回成本須分手續費、適用稅、滑價及放空借券融資，具有來源、日期、每股單位且總額相符，才產生成本假設淨結果。不是實際成交績效。缺成本不算零、觀望或未成交的毛現金零報酬不冒充淨勝率。

混合score停用；原score保留為legacy_score。外資加投信淨買超僅在與成交量同日且完整時除以當日成交量，與股價乖離方向、量比各自呈現。自營商缺值保持未知，不算零。預設排序是股票代號；單維度排序不是兩週上漲概率。舊快取缺觀測日期時標準化比例不可用。舊混合最低分篩選不可作新訊號門檻。

策略比較只標描述性最高模型，best_model_id為null。/api/performance/stats提供research_validation契約。離線入口：

```
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/evaluate_signal_increment.py <歷史JSON資料集> --cutoff YYYY-MM-DD
```

資料必須包含當時訊號、資料可得時間、後續入場／10日終點、完整成本假設的淨結果、同產業／規模／動能對照及來源。不能用目前指標填歷史。政策先固定，訓練／觀察期與holdout隔離10交易日；同股去除重疊。結果僅是宣告來源資料的分組描述性淨超額，不驗證來源真偽、不證因果、統計顯著性或盈利；缺歷史、日曆、對照或時間欄時fail closed。目前沒有宣稱完成實際樣本外驗證。
