# 績效樣本展示契約

交易計畫使用報告日後 5、10 個觀察行情交易日，窗口未滿的 pending 結果可能尚未保存。統計總數僅代表保存結果，不能推算所有未成熟報告。日行情數量不是完整交易所日曆覆蓋證明。

交易 hit 依毛價格報酬大於 0；成本只在有 transaction_cost 時另計 net_strategy_roi_pct，未納入 hit。月度方向及目標判定使用不同定義，不可混成同一策略勝率。未成交、不交易、日內順序不明及資料不足不算 miss。

摘要呈現已評分/保存總數、未評分原因、觀察窗口及成本覆盖。1/1 保留為描述性 100%，不得當 headline、策略勝率或統計顯著性；任何樣本數都不自動標記策略可靠。日期、成本缺欄明示未知，不補造。原始保存資料與計算比率保留。
