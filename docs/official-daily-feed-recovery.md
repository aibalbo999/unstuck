# 官方每日行情備援契約

此文件公開保留免費入口修正的資料契約，個別掃描、報告與執行紀錄留在本機。

`backend/screener_twse_daily.py` 在現有日行情非空但日期落後時，可使用指定日期的 TWSE MI_INDEX `type=ALL` 備援。必須核對回應日期、狀態、具名資料表與欄位，再合併同日期觀測。失敗保留實際來源日期與警示，不能把舊日期行情當成目前資料。

股數保持股數，缺值保持未知。舊日月均價不能套用到新日價格來計算偏離，亦不能代替 20 個交易日基準或成交量比。程式保存來源 URL 與解碼後 JSON 的標準化指紋；該指紋不是原始 HTTP bytes 的雜湊。

相關測試：`tests/test_twse_dated_daily_fallback.py`。這些檢查驗證來源解析與拒收邊界，不代表歷史 point-in-time、價格調整、成交成本或策略獲利已驗證。既有歷史報告與觀察不因此重新計算。
