## 閱讀層改善

- 只嵌入顯示所需的來源狀態、錯誤類型、取得時間與事件日期，不嵌入私有原件收據。
- 冷卻與並行等待明說本次未重複取得；五年不足與比較期衝突明說是證據或涵蓋限制。
- 事件日期使用保存日曆的觀測日期與 14 日範圍，不以查看當天的日期回寫舊判斷。
- 有備援取得紀錄不代表原供應商已恢復，也不能把不同期間或來源當作同一份完整證據。
- 已補抓資料與原報告失敗紀錄並列；新來源資料不取消舊警示、不把舊分析變成最新結論。
- 遷移前讀取來源快照，取得寫鎖後再次核對雜湊，避免遞迴取得檔案鎖或混入同時更新的快照。

尚未補齊的自由現金流期間／完整資本支出、成交量來源口徑、歷史法人原件、護城河研究與未公開事件，
仍保持未核實。需要來源原件或重新分析的項目，不以推算、補零、放寬來源門檻或大量重試消除警示。

## 唯讀盤點工具

```bash
"$(scripts/project_python.sh)" scripts/audit_report_data_gaps.py \
  --index backend/cache/stock_agent_cache.sqlite3 \
  --output backend/output \
  --result /tmp/report-data-gaps.json
```

預設只取最新股票／模式；加 `--all-versions` 可查所有保存版本。
工具只讀現有索引與 artifact，不連資料供應商或模型，也不因最新快照損壞就改取舊版冒充成功。
空白交易欄位仍須結合模式判讀，盤點結果不是自動補值或交易指令。

本機原快照、補抓結果、全量盤點與閱讀遷移收據保存於
`docs/evidence/report-data-gaps/20261018/`，不應連同原件與資料庫直接推送。
